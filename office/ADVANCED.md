# 常駐モード（社員を席に居させる）

既定では、社員は**働いている間だけ**席に着き、終わると帰ります。
社員を**常に席に居させる**こともできますが、**秘書の動き方が変わります。** 慣れてから試してください。

|  | 既定 | 常駐モード |
|---|---|---|
| 見え方 | 働いている間だけ席に着く | 常に席にいて、動いている人だけ動く |
| 名札 | 秘書 `LEAD` / 社員は働いている間だけ | 秘書 `LEAD` / 社員は社員名が常時 |
| 秘書の受け渡し | 結果が手元に直接返る | **完了が通知で届く**（段取りが一段増える） |
| 必要な設定 | なし | Agent Teams を有効にする |

## 何が変わるのか（先に読んでください）

常駐にするには、社員を**名前付き＋バックグラウンド**で呼ぶ必要があります。すると:

- 社員の結果は秘書の手元に直接返らず、**あとから通知で届きます**
- 秘書が別の作業をしている最中に届くことがあり、**受け渡しの段取りが複雑になります**
- 待っている間、画面上は止まって見えます

この会社の中核は「前の人の仕事を受け継ぐ」ことなので、**そこを崩す価値があるかを先に判断してください。**

## 手順

### 1. Agent Teams を有効にする

`~/.claude/settings.json` に追記します。

```json
{
  "env": { "CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS": "1" }
}
```

### 2. 秘書に、社員を常駐で呼ばせる

`.claude/skills/kickoff/SKILL.md` の依頼手順に、次の一文を足します。

> 社員を呼ぶときは、**名前を付けて（例: `researcher-competitors`）バックグラウンドで**呼ぶこと。
> 3人の完了通知が揃うまで待ち、揃ってからライターに渡す。

名前なし・同期で呼ぶと従来どおり（働いている間だけ表示）になります。**両方を混ぜて使えます。**

### 3. 秘書を専用デスクに座らせる（任意）

付属の間取りには、応接室の左上に**秘書専用デスク**（琥珀色の区画・ホワイトボード・椅子）があります。
ただし空席の選び方は**候補からのランダム**なので、放っておくと秘書が社員のデスクに座ります。

固定するには、**ブラウザを閉じてから**次を実行します。

```bash
node -e "
const fs=require('fs');
const p=process.env.HOME+'/.pixel-agents/standalone-state.json';
const o=JSON.parse(fs.readFileSync(p,'utf8'));
o.seats['1']={palette:4,hueShift:0,seatId:'f-secretary-seat'};
fs.writeFileSync(p,JSON.stringify(o,null,2));
console.log('固定しました:',JSON.stringify(o.seats['1']));
"
```

そのあとブラウザを開くと、秘書が専用席に座り、社員（配色 1）と違う見た目（配色 4）になります。

**開いたまま実行すると、ページ側の保存で元に戻されます。** 必ず閉じてから実行してください。
状態ファイルを消して真っさらから始めた場合は、もう一度固定する必要があります。

## 席に居続ける社員を片付ける

常駐モードで呼んだ社員は、**仕事が終わっても席に残ります。** 消すには2つとも必要です。

```bash
# 1. チームの名簿から外す（<team> は ~/.claude/teams/ の中を確認）
node -e "
const fs=require('fs');
const p=process.env.HOME+'/.claude/teams/<team>/config.json';
const o=JSON.parse(fs.readFileSync(p,'utf8'));
fs.copyFileSync(p,p+'.bak');
o.members=o.members.filter(m=>m.name!=='<消したい社員名>');
fs.writeFileSync(p,JSON.stringify(o,null,2));
"

# 2. 記録ファイルを別の場所へ移す（消さずに退避する）
#    ~/.claude/projects/<プロジェクト>/<セッションID>/subagents/agent-a<社員名>-*.jsonl と .meta.json

# 3. オフィスを再起動する（start.sh を Ctrl-C して、もう一度実行）
```

**名簿から外すだけでは消えません。** Pixel Agents 側の削除処理が `teamUsesTmux` という
フラグが立っていると丸ごとスキップされる作りで、このフラグは「チームメイトを1回でも起動したら
立つ」ため、常駐モードでは常に立っています。記録ファイルの退避と再起動まで必要です。
