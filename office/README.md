# オフィス（社員が働く様子を見る）

社員が働いているところを、ドット絵のオフィスとしてブラウザで見られます。

**これは飾りではなく、実際のログを読んで動いています。** 社員が起動したらキャラが席に着き、
ファイルを読んでいるとき・書いているときで動作が変わり、終わると帰ります。

---

## 使い方

会社のフォルダで、こう打ちます。

```bash
node office/start.js
```

ブラウザで **http://127.0.0.1:3100** を開いてください。

> **Windows でもこのままで動きます。** Mac / Linux で `./office/start.sh` を使っても構いませんが、
> zip から始めた方は実行権限が落ちていることがあります（`Permission denied` と出たら
> `node office/start.js` を使ってください）。

そのまま、**別のターミナル**で会社のフォルダに入って `claude` を起動し、`/kickoff` を流します。
社員が席に着く様子が見えます。

> **順番があります。オフィスが先です。** オフィスは初回起動のときに「社員の動きを受け取る口」を
> 登録します。**先に `claude` を起動していた場合は、いったん終了して開き直してください。**
> 起動済みの `claude` はその登録を知らないため、秘書1人しか出ません。

止めるときは、起動したターミナルで `Ctrl-C` です。

- 初回だけ、**ネットから**部品を4つ取り寄せます（30秒ほど）。2回目以降はすぐ起動し、ネットも要りません
- ポートを変えたいときは `node office/start.js 3200` のように指定します
- エディタは何でもよく、VS Code は不要です（Zed・Cursor・ターミナルだけでも動きます）

## 必要なもの

- **Node.js 20 以上**（`node -v` で確認。無ければ https://nodejs.org から）
- **初回だけネット接続**（部品の取り寄せに使います。2回目以降は不要）
- ビルドは不要です。TypeScript も要りません

## 何がどこに書き込まれるか（4つ）

オフィスは**会社のフォルダの外にも書き込みます**（上の3つ）。先に書いておきます。

| 場所 | 何が入るか | いつ |
|---|---|---|
| `~/.claude/settings.json` | 社員の動きを受け取る口（フック）が **14 か所に1行ずつ** | 初回起動時 |
| `~/.pixel-agents/hooks/claude-hook.js` | その口の中身（オフィスに動きを送るだけの小さな部品） | 起動のたびに最新化 |
| `~/.pixel-agents/layout.json` | 付属の間取り（**既にある人のものは上書きしません**） | 初回起動時 |
| `office/node_modules/` | 取り寄せた部品4つ | 初回起動時 |

`~/.claude/settings.json` は **Claude Code の全プロジェクト共通の設定**です。この会社のフォルダ
だけの設定ではないので、他のプロジェクトで `claude` を動かしたときもこの口が呼ばれます
（オフィスを止めていれば、呼ばれても何も起きません）。

やめたいときは、Claude Code の中でこう頼めば消せます。

```
~/.claude/settings.json から pixel-agents のフックを消して
```

## 見え方

| 誰 | 見え方 |
|---|---|
| 秘書（あなたの相手） | ラベルに `LEAD` と出る |
| 社員（リサーチ・ライター・レビュー） | 働いている間だけ席に着き、終わると帰る |

社員を**常に席に居させる**こともできます（`ADVANCED.md`）。ただし秘書の動き方が変わるので、
慣れてからにしてください。

## 間取りを変える

画面左下の **Layout** ボタンから、床・壁・家具・カーペットをその場で編集できます。
色とコントラストも変えられます。編集した結果は `~/.pixel-agents/layout.json` に保存されます。

付属の間取り（近未来配色・社員6席・秘書席つき）を後から適用したい場合:

```bash
cp office/layout.json ~/.pixel-agents/layout.json
```

**ブラウザを閉じてから実行してください。** 開いたまま置き換えると、ページ側の保存で
元に戻されます。

## うまく動かないとき

| 症状 | 原因と対処 |
|---|---|
| 社員が出ない。秘書1人だけ | ブラウザをリロードする。それでも出ないなら `claude` を起動し直す（フックの登録が必要） |
| 別のプロジェクトを見ている | `start.js` / `start.sh` を使わず直接起動していないか確認する。監視先は**起動時のフォルダ**で決まります |
| 誰も出ない | `~/.claude/settings.json` に Pixel Agents のフックが入っているか確認する（初回起動時に自動で追記されます） |
| 「準備に失敗しました」と出て起動しない | 初回だけネットから部品を取り寄せます。接続を確認して `node office/start.js` をもう一度（手動なら `cd office && npm install --omit=dev`） |
