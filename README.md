# AI社員の会社テンプレート

**あなたが CEO。AI社員3名が働く会社**を、自分のパソコンの中に作ります。

CEO（あなた）が指示を1つ出すと、社員3名が動いて成果物が3つ出てきます。

```
CEO（あなた）
   │  「うちの会社を動かして」
   ▼
秘書（Claude）── 仕事を振り分ける
   ├─▶ リサーチ社員 ─▶ output/research-YYYY-MM-DD.md
   ├─▶ ライター社員 ─▶ output/lp-YYYY-MM-DD.md
   └─▶ レビュー社員 ─▶ output/review-YYYY-MM-DD.md
```

---

## 事前にすませておくこと（当日までに）

以下が終わっていれば、当日は 10〜15 分で動き出せます。

- [ ] **Claude Code のインストールとログイン**（**必須**）
  - ターミナルで `claude` と打ってログインし、Claude が起動すればOK
  - ログインは**会社の Claude アカウント**で行います（個人での契約は不要です）
- [ ] **GitHub アカウント**（**任意**。無くても参加できます → [B の手順](#b-zip-から始める-github-アカウント不要)へ）

> 動作確認: ターミナルで `claude --version` と打って、バージョン番号が出れば準備完了です。

**A と B のどちらか一方**を選んでください。**A を推奨**しますが、GitHub アカウントが無ければ B で問題なく参加できます。

### A: GitHub から始める

#### A-1. 自分の会社リポジトリを作る（2分）

このページ右上の緑のボタン **「Use this template」** → **「Create a new repository」** を押します。

- **Repository name**: 好きな会社名（例: `my-ai-company`）
- **Public / Private**: どちらでもOK
- **「Create repository」** を押す

#### A-2. 自分のパソコンに持ってくる（3分）

作ったリポジトリのページで緑の **「Code」** ボタン → URL をコピー。
**ターミナル**（Mac の「ターミナル」アプリ）を開いて、次を打ちます。

```bash
cd ~
git clone <コピーしたURL>
```

`<コピーしたURL>` の部分は、貼り付けで置き換えてください。

→ **[3. その会社に入る](#3-その会社に入る1分)** へ進んでください。

---

### B: zip から始める（GitHub アカウント不要）

#### B-1. zip を受け取って展開する（2分）

1. **Slack で配布された `ai-company-template.zip`** をダウンロードする
   - まだ配られていなければ、その場で「zip をください」と言ってください
2. **ダブルクリック**して展開する（`ai-company-template` というフォルダができます）

#### B-2. わかりやすい場所に置いて名前を変える（3分）

ダウンロードフォルダに置いたままだと迷子になるので、**ホームフォルダへ移動**します。
ターミナル（Mac の「ターミナル」アプリ）を開いて、そのまま次を打ってください。

```bash
mv ~/Downloads/ai-company-template ~/my-ai-company
```

`my-ai-company` の部分は好きな会社名に変えてOKです。

> **うまくいかないときは**、Finder で展開したフォルダをホームフォルダ（家のアイコン）へドラッグしてください。それでも同じことができます。

→ **[3. その会社に入る](#3-その会社に入る1分)** へ進んでください。

---

### 3. その会社に入る（1分）

```bash
cd ~/<フォルダ名>
claude
```

`<フォルダ名>` は、A なら リポジトリ名、B なら `my-ai-company` です。
Claude Code が起動します。**ここからは日本語で話しかけるだけです。**

> **確認**: 起動したら `/kickoff` と打ってみて、候補に出てくればセットアップ成功です。
> 出てこない場合は、フォルダの中で `claude` を起動できていません（`cd` を忘れていないか確認）。

### 4. 動かしてみる（5分）

Claude Code の中で、こう打ちます。

```
/kickoff
```

社員3名が動き、`output/` フォルダに3つのファイルが出てきます。
これで**あなたの会社が動きました**。

## ここから自分の会社にする

### 触るのは `COMPANY.md` だけ

[`COMPANY.md`](COMPANY.md) を開いて、社名・事業・顧客・トーンを自分の会社に書き換えてください。
**このファイル1つを変えるだけで、社員3名の発言も成果物もまるごと変わります。**

書き換えたら、もう一度 Claude Code で:

```
/kickoff
```

さっきと全然違うものが出てきます。これが「AI社員」の正体です。

> **架空の会社で構いません。** 実在する必要はまったくありません。
> 迷ったら「文章のトーン」を大きく変えてみてください。変化が一番わかりやすく出ます。

## 会社の中身

```
あなたの会社/
├── COMPANY.md          ← あなたが書き換えるのはここだけ
├── AGENTS.md           ← 就業規則（秘書と社員の共通ルール）
├── staff/              ← 社員1人 = 1フォルダ
│   ├── researcher/
│   │   ├── AGENT.md    ← この社員の役割・性格
│   │   └── MEMORY.md   ← この社員の記憶（← あなたが育てる）
│   ├── writer/
│   └── reviewer/
└── output/             ← 成果物が出てくる場所
```

### 社員3名

| 社員 | 仕事 | できないこと |
|---|---|---|
| **リサーチ社員** | 競合・市場を調べる | 会社の他のファイルを書き換えない |
| **ライター社員** | LP・紹介文を書く | 調べ物はしない |
| **レビュー社員** | 読んで指摘する | **書き込む手段を持っていない** |

レビュー社員が書き換えられないのは、お願いではなく**権限で担保**しています。
`staff/reviewer/AGENT.md` の `tools:` の行に、書き込み系のツールが入っていないためです。

**「誰に何を任せるか」だけでなく「何を任せないか」も設計する** — これが一番の勘どころです。

---

## 大事な話: 「記憶」は AI が勝手に覚えるものではない

`staff/<社員名>/MEMORY.md` は、その社員の記憶です。

でも、**AI は記憶を持っていません。** 毎回まっさらな状態で起動し、その時に渡された文章しか見ていません。
「記憶しているように見える」のは、`MEMORY.md` を毎回読ませているからです。

→ **育てるのは CEO（あなた）の仕事です。**
社員がいい判断をしたら `MEMORY.md` に1行足す。ズレた仕事をしたら「次はこうして」を1行足す。
それが次回から効きます。これが「AI社員が育つ」ということの実体です。

## 次にやること

### 社員を増やす

`staff/` に新しいフォルダを作り、`AGENT.md` と `MEMORY.md` を置きます。
そのあと、Claude Code の中でこう頼めば、リンクまで作ってくれます。

```
staff/sales/ に営業社員を作りました。会社で働けるようにしてください。
```

### 社員をつなぐ

レビュー社員の指摘を、ライター社員に渡して直させてみてください。

```
output/review-*.md の指摘を writer に渡して、LP を書き直させて
```

**指示を出す人間（あなた）が、社員と社員をつなぐ回線になっています。**
これを自動化していくのが、この先の話です。

## 困ったとき

| 症状 | 対処 |
|---|---|
| **`command not found: claude`** と出る | インストール直後はターミナルが古い状態のままです。**ターミナルを完全に終了（⌘Q）して開き直す**のが一番効きます。それでも出る場合は `~/.local/bin/claude` と打ってみてください |
| 途中で「使用量の上限」と言われた | 社員3名を並列で動かしているためです。運営に声をかけてください |
| `/kickoff` が候補に出ない | フォルダの**中で** `claude` を起動しているか確認（`cd ~/<フォルダ名>` を忘れていないか） |
| 社員が呼ばれず、秘書が自分で書いてしまう | `researcher と writer と reviewer を使って` と明示的に頼む |
| 「そのようなエージェントはありません」と言われる | フォルダを**コピーではなく移動**してください。一部のコピー方法で内部のリンクが壊れることがあります。zip を展開し直すのが確実です |
| リサーチ社員が「未検証」ばかり返す | 社内ネットワークで Web 検索が塞がれています。**正常な動作**です（そう明記する設計） |
| 成果物が出てこない | `output/` フォルダを確認。それでも無ければ「どこで失敗したか教えて」と聞く |

### zip で始めた方（B）向け

| 症状 | 対処 |
|---|---|
| フォルダが二重になっている | `ai-company-template/ai-company-template/` のように入れ子になることがあります。**`COMPANY.md` が直接見えるフォルダ**が正しい場所です |
| `mv` のコマンドでエラーが出る | 展開先が `~/Downloads` ではないのかもしれません。Finder でフォルダをホームフォルダへドラッグしてください |
| `cd` でフォルダに入れない | ターミナルに `cd ` と打ってから、Finder のフォルダを**ターミナルにドラッグ＆ドロップ**すると、正しいパスが入ります |
